## 可重复执行

Windows：执行 `build_windows.bat`。已配置的 GitHub Actions 会分别验证 Linux、Windows 的 CMake 构建及 Windows 批处理路径。远端任务状态以仓库 Actions 实际记录为准。

CTest 提供 4 个测试入口：核心与闭环测试、CSV 仿真运行、未知参数拒绝、缺少输出路径拒绝。核心判据直接检查已知均值、物理量纲及最终闭环行为，不以程序生成的基准文件作为唯一判断依据。

命令行退出码：0=成功，1=文件或数值运行错误，2=命令行用法错误。`--output` 目录不存在时，程序应报错并返回 1。

## 适用边界

20 Hz 指仿真时钟上的控制频率。本程序不检验 Windows 墙钟调度抖动、嵌入式最坏执行时间或真实中断周期。飞轮模型没有电流环、电压限制、反电动势、量化、通信、温度或卫星本体动力学；速度 PI 的结果不能替代真实硬件验证。
